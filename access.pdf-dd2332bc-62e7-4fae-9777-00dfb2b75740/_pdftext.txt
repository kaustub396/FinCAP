1 Problem in 30 seconds
▶Quant factors decay: top-1000 anomalies
lose about 32% after publication; GP
memorises noise.
▶Old LLM+GP hybrids delete bad
formulas and lose diversity.
▶Fix: repair, don’t reject — rewrite only
the truly nonsensical (score 2 or less).
▶Deletion is expensive: a dropped tree takes
its partial signal with it, and a thinner pool
converges faster onto one lucky regime.
▶Local 3B/2B models make the judge cheap
enough to call every generation: $0 API
cost, prompts never leave the workstation,
latency fits the monthly rebalance.
▶The claim stays narrow on purpose: repair
lifts out-of-sample stability, not in-sample
fit, and never widens the risk budget.
2 What each layer does
▶AFM (slow): news mood +
PE/ROE/EPS/BV gives a bull/bear prior,
an economic compass. It drifts over weeks,
so one noisy headline never flips the prior.
▶HMM (fast): 2-state volatility filter.
Calm goes to trend formulas; turbulence
to reversals + quality. Baum–Welch learns
the transitions; Viterbi decodes today’s
state once a day.
▶GP (inventor): 500 trees, depth max 6,
Sharpe minus complexity fitness. The
parsimony term prices in every node, so
bloat is charged from generation one.
▶LLM (editor): Llama rates economics
1–5; Gemma rewrites failures from a
closed vocabulary — at most L ≤5 typed
edits, so a rewrite can never invent a data
source that does not exist.
▶Guards: every repaired tree must compile
through the AST check and pass validation
ranges before it re-enters the pool; a
rewrite that fails never replaces its parent.
▶Settings: AFM FinBERT threshold
τ = 0.5; HMM 2-state Baum–Welch +
Viterbi; GP pop 500, depth max 6; edit list
L ≤5; dollar-neutral top/bottom-15%,
monthly rebalance. The identical setup
runs on Nifty, S&P and SSE — nothing is
retuned per market.
2b Loop + stability (how it runs, why it holds)
GP loop: AFM prior + HMM state →fitness (Sharpe −complexity)
→Llama judge (1–5) →Gemma repair (S ≤2, closed vocab, L ≤5)
→recompile, back into evolution. Trees scoring 3–5 pass untouched,
so the editor spends compute only where the economics is broken. Zero
attrition: every repair compiles, the pool never drops below its 500 trees,
and nothing is discarded for looking unusual — only for scoring low.
Rolling-window Sharpe stays positive (0.855) in turbulent 2017–20 where momentum + trend turn negative. Regime
specialists, not one average model: every rolling window is judged on its own regime, so a calm 2013–16 never has to
average out a hostile 2017–20.

Feature mix of top alphas (paper Fig. 6): intermediate momentum +
volatility scalers dominate. Each bar counts appearances of that feature in the
top-ranked formulas: a trend term you can hold in calm regimes plus a scaler
that trims size when vol rises, with reversals + quality for stress. The
categories stay classical (trend, momentum, volatility, quality), so every
repaired formula still reads like something a desk would write. Because the
inputs stay classical, the repair step can never smuggle in data the GP never
saw.
